# Input:
The Hello World app uses three fixed text entries as input: the student's name, their degree program, and their school. These are added directly into the React Native code using three Text components. The app doesn't need any keyboard input, buttons, or user interaction.

# Process:
The app is built with React Native and Expo. A View component holds the three Text components together. The StyleSheet controls how the interface looks and where everything is placed. The backgroundColor property makes the background yellow. The justifyContent and alignItems properties make the text centered both vertically and horizontally. React Native shows these components when the app starts up.

# Output:
The app shows the student's name, degree program, and school, each on a separate line, all centered on a yellow background. This output shows a simple mobile interface made with React Native components and styling. The program works as expected and follows all the required component limits.
